# Import your tunes

Already keep a list of tunes somewhere? You can add it to Crosstune in one step. Copy the list, paste it in, check it, and add it. It works offline too.

To start, open Settings, then Import and export, and choose Import tunes. If your catalog is empty, the same Import tunes action is on the empty catalog screen.

## What you can paste

Copy your list from Notes, a document, or anywhere else, and paste it into the Your tunes field. These are the rules Crosstune follows.

Put one tune on each line.

```text
Soldier's Joy
```

Bullets, numbers, and checkboxes are fine.

```text
- Cluck Old Hen
1. Red Haired Boy
[ ] Sally Goodin
```

A line that ends with a colon is a heading and is skipped.

```text
Reels:
```

A slash between titles makes two tunes.

```text
Silver Spear / Mason's Apron
```

Anything else stays in the title. You can edit it before you add.

```text
Cluck Old Hen (A, cross-tuned)
```

## Opening a file

If your list is in a text file, choose Open a file and pick a `.txt` file instead of pasting. Crosstune reads it the same way.

On a Mac, or on the web with a mouse or trackpad, you can also drop the file on the import sheet.

## Reviewing before you add

Choose Continue to see the tunes Crosstune found. Nothing is added yet.

- A tune already in your catalog is marked "Already in your catalog" and starts unchecked. Check it if you want a second copy.
- Uncheck any tune you do not want.
- You can change any title before you add.
- Status and genre apply to every tune you add. You can also put them all on a list, either a new one or one you already have.

When the list looks right, choose the Add button, which shows how many tunes it will add. Importing never changes a tune you already have.

## Importing recordings

Import tunes reads tune titles only. To bring in recordings, such as voice memos or audio files from another app, upload them on the Recordings screen. You can upload many files at once.

1. Open Recordings.
2. Choose the upload button at the top of the screen. On an iPhone or iPad, it is the + button.
3. Select one or more audio files.

On a Mac, or on the web with a mouse or trackpad, you can also drop audio files on the Recordings screen.

Each uploaded recording goes to Unfiled. From there, you can file it under a tune.
